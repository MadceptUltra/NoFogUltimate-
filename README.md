# NoFogUltimate-
Tired of fog ruining your view? This mod wipes out every type of fog in Minecraft, including distance haze, underwater murk, lava and Nether atmosphere, so you get crystal-clear visibility in every biome and dimension. One tiny download, and you'll never squint through the mist again.
